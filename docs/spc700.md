# SPC700

## Scope and current state

Own SPC700 registers, flags, instruction execution, local RAM/I/O and timers. SPC700 is independent of the 65C816 and target CPU. IPL data origin/licensing must be resolved before committing any boot image. No SPC700 implementation exists.

## Design direction

Document memory and port semantics, timer divisors and instruction costs from primary research. Scheduler advances APU time deterministically; do not substitute host timing or make the IOP responsible for SNES timing by default.

## Verification criteria

Test every opcode/addressing class, flags, stack, multiplication/division, decimal adjust, bit operations and sleep/stop interactions. Verify communication races, timer wrap/reset and long-run clock ratios with targeted integration fixtures.

## Research and decisions

No emulation semantics are claimed verified by bootstrap. Before implementation,
record the exact hardware reference, section/revision and independently authored
regression evidence. SDK documentation is not a source for SNES behavior.
Intentional approximations: none implemented. Known subsystem bugs: not yet testable.
